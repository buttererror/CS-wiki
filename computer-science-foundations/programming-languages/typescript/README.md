# TypeScript

**Reading status:** Not read yet

## Scope

TypeScript is a programming language and static type checker that builds on
JavaScript. It adds a type-system layer to help developers describe, infer, and
check program relationships before JavaScript executes.

TypeScript does not replace JavaScript runtime behavior or runtime validation.
Most type-only syntax is erased when code is emitted as JavaScript.
