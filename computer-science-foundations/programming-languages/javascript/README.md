# JavaScript

**Reading status:** Not read yet

## Scope

JavaScript is a programming language with its own syntax, bindings, functions,
objects, modules, and evaluation rules. It is distinct from the browser APIs
often used with it: `document`, `fetch`, timers, and rendering are supplied by a
host environment rather than the language itself.
