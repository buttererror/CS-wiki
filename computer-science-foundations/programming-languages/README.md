# Programming Languages

## Purpose

Programming Languages studies the languages used to express computations:
their syntax, semantics, type systems, runtime behavior, and programming
models. A language concept can apply across browsers, servers, frameworks, and
tools.

This directory owns language-level explanations. Browser-provided APIs belong
to [Browser Runtime](../../frontend-development/browser-runtime/README.md), and
technology-specific behavior belongs with the relevant framework or tool.
