# Frontend Development

## Purpose

This directory collects notes about user-interface development, browser
behavior, frontend frameworks, rendering, state, styling, and related client
technologies.

The directory is a practical subject area rather than a claim that every file
occupies the same abstraction level. It contains concepts, frameworks,
language-specific notes, and working study material that can be refined into
more focused subdirectories later.

## Area Map

```text
Frontend Development
│
├── Browser and rendering concepts
├── UI frameworks and libraries
│   ├── React
│   ├── Next.js
│   └── Vue
│
├── State, effects, context, and reducers
├── Styling and component presentation
└── Cross-platform client UI
    └── Flutter
```

Flutter is included as related client-interface material. It is a
cross-platform UI toolkit rather than a browser frontend framework and may gain
its own area when the wiki develops more mobile or cross-platform content.
