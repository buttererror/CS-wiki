# Version Control

**Keywords:** version control, git, branches, commits, merges, reflog, cherry-pick, detached HEAD

## Purpose

Version control is the practice of tracking changes to source material over
time so people can branch, compare, merge, recover, and collaborate safely.

It sits under Software Development Practices because it shapes how work is
organized and synchronized, not how the runtime system behaves.
