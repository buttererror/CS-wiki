# Repository Documentation

## Purpose

This directory contains documentation about maintaining and evolving the CS
Wiki itself. It is separate from the subject-matter knowledge base.

```text
Wiki content
→ explains Computer Science and software-development topics

Repository documentation
→ records how the wiki is organized, maintained, and developed
```

## Maintenance Records

Maintenance records explain completed repository-wide organization or content
passes and identify relevant follow-up work.

- [2026-08-05 Taxonomy and Organization Pass](maintenance/2026-08-05-taxonomy-and-organization.md)

## Plans

Plans describe proposed changes to the wiki's publishing or development
infrastructure. They describe intended work, not current behavior.

- [Static Wiki and Offline PWA Plan](plans/static-wiki-pwa.md) — proposed
  static-site generation, offline access, local search, and GitHub Pages
  deployment.

## Documentation Boundaries

- Subject explanations belong in their canonical knowledge-area directories.
- Completed organization passes belong under `maintenance/`.
- Proposed repository or publishing work belongs under `plans/`.
- A plan should not be presented as implemented behavior until the work is
  completed and the relevant documentation is updated.
